# Obtain proof of ownership for speakbusy.com

## Current state
- Custom domains: `speakbusy.com` (primary) and `www.speakbusy.com`.
- Domain status in Lovable: **active**, **connected**, purchased through Lovable (`mode: "buy"`).
- Lovable acts as the registrar/management layer; there is no separate registrar dashboard login for you.

## What payment providers usually accept as proof of ownership
1. A WHOIS lookup printout showing the registrant name and registration/creation date.
2. A domain purchase invoice or receipt from the registrar.
3. A screenshot of the domain management page with your project/account visible.

## Steps to get the document
1. Open **Project Settings → Project section → Domains** in Lovable.
2. Open the three-dot menu (⋯) for `speakbusy.com` and click **Configure**.
3. Look for any **Manage domain**, **Registration details**, **Receipt**, or **Download invoice** option. If present, download the registration receipt or screenshot the details page.
4. If no ownership document is available in the UI, contact **Lovable support** with the request below.

## Alternative self-service check while waiting
- Run a public WHOIS lookup for `speakbusy.com` (e.g., via who.is or whois.domaintools.com) to see whether the registrant details are public or privacy-protected. If they are public, save/screenshot the result as supplementary evidence.

## Expected outcome
You receive an official document from Lovable or the underlying registrar showing the registrant name and registration date for `speakbusy.com`, which you can submit to the payment provider.
